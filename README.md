# ✈️ Voyexa – AI-Powered Travel Super App

## Overview

Voyexa is a UI/UX case study designed in Figma to simplify travel planning, booking, itinerary generation, and trip management.

## Problem Statement

Travel planning is fragmented across multiple applications. Users often switch between booking platforms, itinerary planners, maps, and budget trackers.

## Solution

Voyexa combines trip planning, destination discovery, AI itinerary generation, and travel management into a single platform.

## Features

- Splash & Onboarding
- Login & Sign Up
- Home Dashboard
- Explore Destinations
- Destination Details
- Trips Dashboard
- AI Trip Planner
- Profile Management
